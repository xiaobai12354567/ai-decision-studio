# AI 个人决策推演室 · MVP 需求文档

## 1. 产品定位

一款帮助用户推进个人重要决定的 AI Web 产品。

用户描述正在纠结的问题，AI 帮助梳理选项、探索可能情境、明确关键取舍，最终形成可执行的下一步行动。

**核心目标：让用户从“迟迟做不了决定”，走到“知道下一步该做什么”。**

## 2. 目标用户与场景

面临重要个人选择、反复思考但难以行动的用户。

MVP 优先支持职业与城市选择，例如：

- 是否跳槽、转行或留在当前岗位。
- 是否接受一个新的工作机会。
- 是否去另一座城市工作、生活。

## 3. 核心使用流程

**描述困境 → 补充关键条件 → 确认选择路径 → 探索情境 → 梳理取舍 → 确定下一步行动**

用户可以随时修改条件、切换路径或返回前面的步骤。

## 4. 主要功能

### 4.1 创建决策

用户用自然语言描述问题，例如：“我想去上海工作，但担心生活成本和离家太远。”

AI 识别本次决策的核心问题，并通过少量追问补充：

- 希望获得的改变。
- 已有选项。
- 时间、预算、家庭等现实约束。
- 最担心的事情。

输出一份可编辑的决策概况，供用户确认。

### 4.2 生成与编辑选择路径

AI 根据决策概况，生成两到三条有实质差异的路径，包括可以分阶段尝试的选项。

例如：

- 留在当前城市，寻找新的工作机会。
- 先拿到外地的工作机会，再搬家。
- 先短期体验目标城市，再决定是否迁移。

每条路径展示主要收益、代价和关键前提。用户可以新增、修改或删除路径。

### 4.3 交互式情境推演

用户选择一条路径，AI 基于已知条件生成具体的可能情境，帮助用户理解实际生活中的取舍。

每个情境包含：

- 一个明确的时间点或事件。
- 可能遇到的变化与困难。
- 产生这一情境的依据与假设。

用户可以表达感受、纠正假设，或继续探索“如果发生这件事，接下来怎么办”。

MVP 采用有限的情境卡片和分支，避免无限展开。用户可以切换路径进行比较。

**所有情境均为探索材料，不作为未来预测；不提供缺乏依据的成功率或确定性结论。**

### 4.4 修改条件并更新推演

用户可以在探索过程中修改关键条件，例如积蓄、收入、可接受的风险或家庭安排。

AI 标明受影响的路径与情境，说明变化原因，并更新相关内容。保留用户此前的反馈，发生冲突时提示重新确认。

### 4.5 决策总结与下一步行动

探索结束后，AI 生成可编辑的决策总结，包括：

- 当前更倾向的选择及原因，也允许暂不选择。
- 用户看重的收益与不可接受的代价。
- 尚未确认、可能改变判断的关键信息。
- 一到三个可执行的下一步行动。

每个行动写明：做什么、要验证什么、完成后如何帮助判断。

用户选择一个行动作为本次决策的下一步。产品不强制用户立即做出最终决定。

### 4.6 保存与回访

自动保存决策内容，用户可以返回继续探索。

用户完成行动后，可以记录结果，AI 据此更新决策总结，并帮助确定是否做决定或继续验证。

## 5. 基本页面

| 页面       | 主要内容                                             |
| ---------- | ---------------------------------------------------- |
| 决策列表页 | 创建决策、查看历史决策及当前进展                     |
| 决策工作台 | 决策概况、选择路径、情境探索、条件修改               |
| 决策总结页 | 当前倾向、关键取舍、待确认信息、下一步行动及结果记录 |

## 6. MVP 范围边界

第一版暂不包含：

- 医疗、法律、投资等专业决策。
- 多人共同决策与社区讨论。
- 自动替用户执行行动。
- 复杂的人生模拟、人格测评与无限分支。
- 外部账户、日历等服务集成。

## 7. 核心验证指标

优先验证产品是否真正推动了用户行动：

- 用户是否完成探索并选定下一步行动。
- 用户是否实际完成该行动并记录结果。
- 用户是否认为自己的决定获得了推进。

**MVP 成功的核心信号：用户离开时，能明确说出“我接下来要做什么，以及为什么要做这件事”。**
