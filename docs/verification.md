- PostgreSQL 17.11：Windows 到 WSL 私有 IP 5433 的连接、认证、事务读写和中文往返。
- Prisma 7.10.1：初始迁移与决策推演相关表的增量迁移已应用，未重置原数据。
- 类型检查与生产构建通过。
- 业务单元测试：依赖传播、硬约束不能遗漏、非法条件引用、分支数量与深度边界。
- 基础接口集成：创建、确认、刷新读取、会话隔离、旧版本拒绝、跨源请求拒绝、输入校验。
- 独立模型测试服务集成：路径、情境、两层/六个情境边界、反馈保留、条件变更、局部更新、总结、行动选定、完成结果、重新总结保留历史、请求幂等、同时生成拒绝、生成期间编辑使旧结果失效、模型失败回滚、模型非法引用拒绝、路径上限及软删除历史保留。

- 浏览器实际操作：创建、概况编辑/自动保存/确认、真实路径与情境生成、反馈保存、总结展示、选定行动、记录完成结果、进入回访状态。窄屏布局已目视检查。

## 已知范围与后续验证

- 模型仍可能给出不合适的假设和取舍，需要用户确认；结构与引用校验不等于事实正确。当前真实样本数量有限，需要持续补充职业和城市选择案例做人工评测。
- 条件依赖使用模型候选并强制纳入预算/家庭约束，新增条件或缺少依赖时保守扩大失效范围，可能比理论最小范围多更新一些内容。
- 任务记录支持失败/过期状态和重试，没有后台执行队列，不承诺页面断连后一定继续执行。
- 生成当前返回完整 JSON 与实际等待状态，未做逐字流式显示。
- 概况自动保存；路径、总结和反馈通过明确按钮保存。概况未保存草稿暂存当前标签页，关闭标签页后不保证保留。
- 列表当前最多返回最近 50 份决策；尚无跨设备账号和分页界面。
- 浏览器跨平台、大规模并发与完整无障碍审计尚未执行。当前服务用于本地开发验证，未发布到公网。
